# 官网视觉风格、布局和交互设计规范

状态：**未来前端设计约定**。当前只交付后端及 Swagger 页面，本文件不代表已有业务界面，也不声称复刻参考网站视觉。

## 视觉方向

采用现代中药房与生产仿真控制台的表达：浅色背景、深绿导航、清晰的数据层级。优先展现流程、资源占用和异常位置，减少装饰。

| 设计变量 | 建议值 | 用途 |
|---|---|---|
| `color-primary` | `#16645B` | 主操作、当前流程 |
| `color-background` | `#F5F7F5` | 页面背景 |
| `color-surface` | `#FFFFFF` | 面板、表格 |
| `color-text` | `#18322E` | 主文本 |
| `color-muted` | `#526B65` | 次要信息 |
| `color-success` | `#1F7653` | 完成 |
| `color-warning` | `#8A5A00` | 排队、暂停 |
| `color-danger` | `#B42318` | 故障、报警 |

中文使用系统字体栈 `"Microsoft YaHei", "PingFang SC", sans-serif`。正文建议 14–16px，关键数据 24–32px；间距以 4px 为基础，主要区块间距 24px，圆角 8px。落地时重新校验实际对比度。

## 页面布局

桌面端使用左导航、顶部仿真时钟和工作区。工作区包含总览指标、流程示意、批次队列与设备状态。宽度低于 1024px 时收起导航，表格允许横向滚动，关键操作保持可见。

流程节点显示中文名称、状态、进度、设备名及排队原因；清洗节点必须可见，不能在配发后直接把锅标为空闲。温度曲线注明“仿真采样”，时间轴注明“虚拟时间”。

## 交互原则

- 全局时钟暂停与单批次暂停分别显示。自动运行时禁用手动推进，并解释需先暂停。
- 故障报警点击后定位到设备和受影响批次；“确认报警”和“修复设备”使用独立操作。
- 取消批次后显示“待倒渣清洗”，直到后端返回最终 `cancelled`。
- 暂停状态持续占用工位，避免界面误导用户认为资源已释放。
- 用文字、图标和颜色共同表达状态。键盘焦点清晰，动态推送不抢焦点。
- 接口失败保留用户输入；409 显示业务原因，422 关联到具体字段，网络中断显示连接状态。
- 展示“流程仿真”标识，示例使用匿名编号。
